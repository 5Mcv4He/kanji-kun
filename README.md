## 看一眼就能用

**音训判断，6 条。** 看到一个日语词，第一秒决定走音读还是训读：

| # | 看到什么 | 判断 | 靠谱率 |
|---|---------|------|--------|
| 1 | 多汉字 + 无假名尾巴 | 音读 | 96% |
| 2 | 有假名尾巴 | 训读 | 90% |
| 3 | 孤零零一个汉字 | 训读 | 65% |
| 4 | 身体/自然/亲属词汇 | 训读信号 | — |
| 5 | 入声尾(くつちき) + 无假名 | 音读 | 80% |
| 6 | 抽象/数字概念 | 音读信号 | — |

总覆盖 **91%**。剩下 9% 你知道要查字典。

**自他对应，10 个模式，学会一次终身受用：**

```
まる↔める  がる↔げる  く↔ける  る↔す  れる↔る
かる↔ける  う↔える  つ↔てる  ぶ↔べる  む↔める
```

看到 〜める，自动词大概率 〜まる。看到 〜げる，自动词大概率 〜がる。不是一个一个记——一个模式管一批。

**送假名词类，9 条。** 假名尾巴直接暴露词类：

| 假名尾巴 | 词类 |
|---------|------|
| 〜る | 动词 |
| 〜く/ぐ/す/む/ぶ | 五段动词 |
| 〜い/しい | 形容词 |
| 〜える | 一段他动词 |
| 〜れる | 被动/可能/自动 |
| 〜り/き/み | 名词 |

**省掉 75% 的账：**

```
4,316 表面实例
    ↓ 活用形归并（書く/書きます/書いて → 同一个东西）
1,892 不同(汉字,读法)对
    ↓ 形态词根归并（上がる/上げる/上がり → 同一词根）
1,703 独立词根
    ↓ 跨级复用（N4 有 25% 在 N5 已出现）
~1,770 逐级新词根
    ↓ 词干连带（学了「口=くち」→「朽=くち」只需确认）
~1,087 有效记忆项 + 25 条规则
```

## 怎么做到的

不是想了几条思路——是写代码跑完的。

三个方向穷举，全死了：

- **规则推导**：所有语法模式写成 if-then，覆盖率上限 21%。每条规则都被反例撕烂。
- **特征交叉**：部首/语义/送假名/拍数两两交叉，最强信号 1 bit ≈ 抛硬币。
- **ML 聚类**：30+ 维特征跑 K-Means，聚类只看见音韵相似性——深层结构不存在。

这意味着两件事。第一，训读确实不存在全局推导规则——帮你省下继续找口诀的时间。第二，你不需要规律——因为 75% 的东西本来就不该作为独立记忆项存在。

## 已验证的发现

**肯定（10 项）：**
音训判断 6 条规则覆盖 91% / 自他对 10 模式 / 送假名 9 条规则 / 帕累托频率优先 / 词干连带效应 / 跨级复利（25–47%复用）/ 活用形归并 56.2% / 形态派生归并 10.0% / 部首锚点 97.3% 覆盖 / 陷阱全标记（90+123+70+29）

**否定（5 项）——同样重要：**
形近字极少共享读法（0.2–0.6%）→ "训读声旁"不存在 / 部首不能预测读法 / 语义域不能预测读法 / ML 未发现隐藏结构 / 送假名不能预测读法结尾
