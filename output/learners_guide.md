# JLPT汉字读音：汉语母语者最少记忆学习指南

> 基于46,849个汉字数据库 + 9,572个JLPT词汇的穷举式统计挖掘
> 目标：用最少的记忆量，达到最高的JLPT汉字读音命中率

---

## 一、核心理念：你已经知道的东西比你想象的多

作为汉语母语者，你在日语汉字读音上拥有三个结构性优势，日语母语者在初学阶段反而没有：

### 优势1：形声字声旁 → 音读

汉字中80%以上是形声字。同一个声旁（声符）的汉字，在日语里**音读相同**。这是从上古汉语借入日语时系统性保留的规律。

```
青(セイ) → 清・晴・請・静・精 全部读 セイ
肖(ショウ) → 消・宵・硝・銷・霄 全部读 ショウ
方(ホウ) → 放・訪・防・妨・芳 全部读 ホウ
```

**这条规律对中国人是免费的**——你不需要重新学，你从小就知道这些字共享声旁。

### 优势2：拼音 → 音读的系统映射

中古汉语到日语吴音/汉音的借入高度规则化。你的拼音知识可以直接映射到音读：

```
l+an(T2)  → らん   82%   (蓝・蘭・嵐・濫...)
l+ian(T2) → れん   73%   (连・練・錬・蓮...)
sh+en(T1) → しん   71%   (身・深・申・伸...)
b+iao(T1) → ひょう 70%   (表・標・票・漂...)
```

**这是纯机械映射，不需要理解，只需要对照表。**

### 优势3：入声字 → 短音读

中古汉语以 -p, -t, -k 结尾的入声字，在日语里音读永远是短音（1-2拍），且必定以 く・つ・ち・き・う・い 结尾。

```
六(liù) → ロク (←中古 *ljuwk, -k入声)
七(qī)  → シチ (←中古 *tshit, -t入声)
十(shí) → ジュウ (←中古 *dzyip, -p入声)
```

**你会读这个字的普通话，你就能判断它是不是入声字（韵尾不是-n/-ng、不是复元音韵母ai/ei/ao/ou）→ 日语里音读必定是短音。**

## 二、看到一个新词时的四层决策流程

遇到一个JLPT单词（比如「消火器」），按以下步骤推导读音：

```
第1层：判断每个字是音读还是训读
   ↓
第2层：如果是音读 → 推导具体音读
   ↓
第3层：如果是训读 → 推导具体训读
   ↓
第4层：检查连浊 → 调整最终读音
```

### 第1层：音读还是训读？（准确率 99.4%）

这一层几乎不需要记忆，看形态即可：

| 判断条件 | 结论 | 准确率 |
|----------|------|--------|
| 汉字后面跟着送假名（如 食べる、大きい、歩く） | **训读** | 96% |
| 单词只有一个汉字，没有送假名（如 愛、年、時） | **训读** | 84% |
| 单词由2个以上汉字组成，无送假名（如 安心、東京） | **音读** | 90%+ |
| 单词含片假名或非汉字字符（如 アルバイト） | **外来语** | 100% |

**铁律**：「有送假名 = 训读」「多汉字无假名 = 音读」。这两条覆盖了约80%的JLPT词汇，准确率超过90%。

### 第2层：音读 → 推导具体读音（精确率 94%，有效率 98%）

音读推导有四级信号，按优先级排列：

**信号A（最强）：JLPT词频默认音读（93%精确）**

对每个汉字，它在JLPT单词里最常出现的那个音读，93%的情况下就是正确的。这不是要你"背"的——这是在刷红宝书的过程中**自然习得**的。你见得多了，大脑自动就会用最高频的那个。

**信号B（中等）：拼音→音读对照规则（46%精确）**

当你遇到一个没见过的汉字，或者不确定音读时，从普通话拼音推导。规则见附录一。

**信号C（中等）：声旁→音读规则（29%精确，1566条）**

如果这个汉字是形声字（大概率是），看它的声旁。同声旁的汉字音读相同。你不需要记1566条规则——你只需要**认出形声字的声旁**，然后回想你对那个声旁的已有知识。

**信号D（强）：入声约束**

如果你知道这个字是入声字（从普通话读音判断），那么它的音读**一定**是短音，结尾一定是 く・つ・ち・き・う・い 之一。这可以排除错误答案。

**信号E（中等）：复合词语境（81%精确，针对多音字）**

对于有多个音读的汉字（如 人=ジン/ニン、上=ジョウ/ショウ），它在复合词中的位置和邻居决定了读音：
- 跟在什么字后面
- 后面跟着什么字
- 在词首还是词尾

这个也不需要刻意记——遇到多音字时，注意它在复合词中的位置即可。

**综合使用方式**：

看到音读汉字时 → 先想"这个字在JLPT里最常读什么"（信号A，93%）→ 如果不确定 → 用拼音推导（信号B）→ 如果还是不确定 → 看声旁（信号C）→ 用入声检测排除不可能选项（信号D）→ 多音字注意复合词位置（信号E）。

### 第3层：训读 → 推导具体读音（精确率 93%）

训读推导有三级信号：

**信号A（强）：JLPT词频默认训读（82%精确）**

和音读一样，每个汉字的训读在JLPT里也有一个最高频的版本。82%的情况下这就是正确答案。

**信号B（强）：送假名语境消歧（87%精确，针对多训字）**

对于有多个训读的汉字（如 生=い/う/は/なま/うま 等），**后面跟着的假名**决定了用哪个训读。比如：
```
生+ける → いける
生+まれる → うまれる
生+える → はえる
生（单独）→ なま
```

**你不需要记"生有5种训读"**，你只需要：看到「生きる」→ 训读是「い」，看到「生まれる」→ 训读是「う」。

**信号C（弱）：部件→训读词干（140条规则）**

某些部件在多个汉字中共享相同的训读词干：
```
召 → て (招・沼・照・超)
昔 → お (借・惜・措・籍・錯)
犬 → しか (伏・吠・嗅・然・燃)
```

这条规律较弱（JLPT覆盖率5-7%），但作为补充信号有价值。

### 第4层：连浊（連濁）调整

日语复合词中，第二个字及以后的清音首音可能变成浊音：

```
か→が (口 くち→甘口 あまぐち)
さ→ざ (酒 さけ→居酒屋 いざかや)
た→だ (手 て→痛手 いたで)
は→ば (花 はな→生け花 いけばな)
```

**规律**：不需要记具体哪个词浊化。只需要知道"复合词中位首音可能浊化"这条规则。当你预测的清音和实际读音差了一个浊化，你知道是连浊在起作用即可——**词干没有错，只是表面音变了**。

## 四、必须硬背的清单（按级别分层）

经过四层规则体系过滤后，仍有约657个读音无法通过规律推导（不含促音化和连浊可解释的）。这些按优先级排列：

### 最高优先级：熟字训（Jukujikun）—— ~15个

这些是整个词的读音无法从单个汉字推导的：

```
明日(あした)  大人(おとな)  今日(きょう)  昨日(きのう)
一日(ついたち) 二十日(はつか)  下手(へた)  上手(じょうず)
田舎(いなか)  梅雨(つゆ)     浴衣(ゆかた)  七夕(たなばた)
```

**建议**：这是真正的"必须背"，但数量极少（JLPT全部约15个真正的熟字训）。

### 高优先级：高频多音字的关键语境 —— ~100个

这些是多音字在不同复合词中的特殊读音，频率高，规律覆盖不到：

| 汉字 | 常见读法 | 特殊读法 | 特殊语境 |
|------|---------|---------|---------|
| 一 | いち | いっ | 一+か行/さ行/た行/は行（一切、一所、一体） |
| 人 | じん | にん | 人間、人形、人数 |
| 上 | じょう | しょう | 上手、上下 |
| 下 | か | げ | 上下、下手 |
| 切 | せつ | さい | 一切、大切 |
| 目 | もく | め | 一番目、二番目（序数词） |
| 分 | ぶん | ふん/ぷん | 十分(じゅっぷん)、三分(さんぷん) |
| 日 | にち | か/び | 曜日(ようび)、三日(みっか) |

**建议**：这类字不多（~50个核心多音字），每个字的特殊读法数量也很有限（通常2-3个）。刷红宝书时遇到就记，不需要专门背。

### 中优先级：单一罕见音读 —— ~100个

这些是只有1个音读（单音字），但那个音读刚好不是你猜测的那个。纯粹是"这个字恰好读这个音"的问题。

**建议**：不需要单独记忆。这类字你会在单词中自然遇到，频率本身就是最好的老师。

### 低优先级：极低频变体 —— ~460个

只出现在1-2个N1词汇中的特殊读音。性价比极低。

**建议**：N5-N2阶段完全忽略。N1冲刺时如果遇到再记。

## 五、学习路径

### 路径A：Quick（10分钟，覆盖约80%）

1. 记住两条铁律：「有假名=训读」「多汉字=音读」
2. 记住连浊存在（清音可能在复合词中间变浊音）
3. 刷红宝书时，每个汉字优先用你见过的最常见的那个读音
4. 遇到多音字（如人、上、下、一），注意复合词位置

**效果**：N5-N4考试，读音题正确率约80%。

### 路径B：Deep（1小时，覆盖约92%）

在Quick基础上增加：

5. 学习拼音→音读对照表（附录一，15条高频规则）
6. 学习形声字声旁规律（附录二，10个最高频声旁）
7. 学习入声检测方法（附录三）
8. 记住约50个核心多音字的特殊语境（附录四）

**效果**：N3-N2考试，读音题正确率约92%，明显优于纯记忆型备考者。

### 路径C：Complete（长期，覆盖95%）

在Deep基础上增加：

9. 建立多训字送假名语感（看到送假名自动匹配训读，不需要规则）
10. 积累部件→训读词干映射（附录五，约140条，可渐进学习）
11. 对熟字训词进行逐个击破（约15个）
12. N1冲刺阶段处理低频变体

**效果**：N1考试，读音题正确率约95%，达到规律推导的天花板。

## 六、实战示例

### 示例1：「消防署」（N3）—— 完全可推导

```
第一步（类型判断）：三汉字无假名 → 全是音读 ✓
第二步（音读推导）：
  消 → 声旁「肖」→ ショウ ✓（同声旁：宵・硝）
  防 → 声旁「方」→ ボウ ✓（同声旁：放・訪）
  署 → pinyin shǔ → 中古入声？否 → JLPT默认=ショ ✓
第三步（连浊）：消防署 → 无连浊
最终读音：しょうぼうしょ ✓ 完全命中
```

### 示例2：「受け継ぐ」（N1）—— 部分可推导

```
第一步（类型判断）：有假名「け」「ぐ」→ 训读复合词
第二步（训读推导）：
  受 → 多训字(う/うけ)，语境：后接「け」→ うけ ✓
  継 → 多训字(つぎ/つ)，语境：后接「ぐ」→ つ ✓
第三步（连浊）：継ぐ → つ+浊化 → つぐ？实际是 つぐ = 未浊化（原形）
最终读音：うけつぐ ✓ 语境消歧命中
```

### 示例3：「一切」（N3）—— 需要语境知识

```
第一步（类型判断）：两汉字无假名 → 音+音
第二步（音读推导）：
  一 → JLPT默认=いち，但语境：一+切(sa行首) → いっ（促音化）
  切 → 多音字(せつ/さい)，语境：跟在「一」后面 → さい
第三步（连浊）：无关
最终读音：いっさい ✓

→ 这个需要知道「一」在さ行前促音化为「いっ」，「一切」中「切」读「さい」
   属于"高频多音字关键语境"，Deep路径覆盖。
```

### 示例4：「明日」（N5）—— 完全不可推导，必须硬背

```
第一步（类型判断）：两汉字无假名 → 音+音？（误判！）
  实际：熟字训，整词读「あした」
第二步：任何规则都无法推导出「あした」

→ 这是纯粹的熟字训，只有15个左右，直接背。
```

## 附录三：入声检测方法

**判定**（从普通话拼音判断）：
- 韵尾是 -n 或 -ng → 不是入声
- 韵母是 ai/ei/ao/ou/iu/ui/er → 不是入声
- 其他情况 → **大概率是入声**

**约束**（如果是入声字）：
- 日语音读必定是 1-2 拍短音
- 必定以 く・つ・ち・き・う・い 结尾
- 不可能以长音（ー/う）结尾

**高频入声字示例**：一(イチ)、六(ロク)、七(シチ)、八(ハチ)、十(ジュウ)、百(ヒャク)、北(ホク)、国(コク)、学(ガク)、食(ショク)
