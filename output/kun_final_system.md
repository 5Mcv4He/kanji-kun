# 训读终结

## JLPT训读学习完全系统

> 基于 8,375 JLPT词汇的逐字标注统计分析。
> 数字可追溯。主张可验证。学完即止。

---

## 序章：先看一个数字

JLPT N5到N1的全部词汇中，表面上你需要掌握的训读实例是 **4,316 个**。

如果每遇到一个词就记它的读法——你需要记 4,316 次。

而实际上，由于日语本身的结构、你作为中文母语者已有的知识、以及按最优顺序学习带来的连带效应——真正需要你**有意识地坐下来记忆的，大约 1,100 项**（加上 25 条一次性规则）。

```
4,316 表面实例
    ↓ 活用形归并（書く/書きます/書いて → 同一个东西）
1,892 个不同的(汉字,读法)对
    ↓ 形态派生归并（上がる/上げる/上がり → 同一词根的不同形式）
1,703 个独立词根
    ↓ 逐级递进（N4有25%在N5已经会了，不必重新学）
~1,770 逐级实际新增（跨五级累计）
    ↓ 词干连带（学了「口=くち」→「朽=くち」只需确认，不用从头记）
~1,087 有效记忆项（+ 25条规则，一次学会终身受用）
```

**从 4,316 到约 1,100。需要记的，不到表面数字的四分之一。**

剩下的四分之三不是靠"技巧"省掉的。它们是日语这门语言本就如此——你只是被传统的学习方式误导了，以为它们都需要记。

接下来，逐层说清楚这四分之三是怎么被划掉的。

但在那之前，先确认一件你早已拥有但可能没意识到的事：

### 你是中国人

这意味着三件事：

**第一，汉字识别不用学。** 看到「食」，你知道它长什么样、什么意思。一个英语母语者需要同时记住形、义、音读、训读——四个映射。你只需要记音读和训读两个。形和义是出厂自带的。

**第二，音读约等于中文发音。** 「電話」= でんわ ≈ dianhua。「学校」= がっこう ≈ xuexiao。音读对你而言是"辨认"而非"记忆"——听到的时候反应一下即可。

**第三，汉字的语义空间是共享的。** 「水」在日语里的意思和你脑子里"水"的意思，是一样的。不存在欧美学习者那种"先学概念再学符号"的翻倍工作量。

三条加起来意味着什么？**日语中唯一需要你从零建立的映射，是训读。** 音读≈中文，汉字形义你已经会了，语法靠规则——只有训读，汉字你知道，但日语里读什么，没有参照系。

所以训读是日语学习中**唯一真正需要"记"的东西**。而本系统做的全部事情，就是把这个唯一需要记的东西压到它本来该有的大小。

## 第一章：不记层——语法自带的东西

你不需要记"X的读法是Y"，因为语法已经替你管了。

### 1.1 活用形（不记）

动词和形容词的词尾变化是语法，不是词汇。

你学的是「書=か」这个词干。至于 書く、書きます、書いて、書いた、書けば、書ける——全是同一个词干的活用。日语语法规则决定了它们各自的形式，不需要你为每一种形式单独建立记忆。

V9 数据中，活用形产生的表面实例占全部训读实例的 **23%–38%**（取决于级别）。仅此一项，N1 就从 1,333 例减到 824 对——活用形虚增了 509 例（38%）。

这个不需要你做任何事。只需要心里清楚：看到同一个汉字的同一个假名出现在不同词尾中（書く→書きます→書いて），它们不是一个一个的独立项，是同一个东西换衣服。

### 1.2 自他对应（不记）

日语自动词（不及物）和他动词（及物）之间有一套系统的形态对应。这不是零散的巧合，是日语的语法架构。

十个模式，终身学一次：

| 自动词尾 | 他动词尾 | 例 |
|---------|---------|-----|
| ～まる | ～める | 高まる↔高める、集まる↔集める |
| ～がる | ～げる | 上がる↔上げる、下がる↔下げる |
| ～く | ～ける | 開く↔開ける、続く↔続ける |
| ～る | ～す | 出る↔出す、直る↔直す |
| ～れる | ～る | 切れる↔切る、売れる↔売る |
| ～かる | ～ける | 助かる↔助ける、掛かる↔掛ける |
| ～う | ～える | 変わる↔変える、伝わる↔伝える |
| ～つ | ～てる | 立つ↔立てる |
| ～ぶ | ～べる | 並ぶ↔並べる |
| ～む | ～める | 止む↔止める、縮む↔縮める |

学会这十个模式之后，所有遇到的自他动词对你自动推导。不需要一对一对记。看到～める就知道自动词大概率是～まる，看到～げる就知道自动词大概率是～がる。

按级别覆盖的训读实例比例：N5=3.9%、N4=10.2%、N3=9.5%、N2=11.9%、N1=7.3%。在 N2 级别，超过十分之一的训读实例被这套系统自动覆盖。

### 1.3 送假名告诉你词类（不记）

看到一个带送假名的词，假名本身已经告诉了你它是什么词类。不需要额外判断：

| 送假名 | 词类 | 例 |
|--------|------|-----|
| る | 动词（一段/五段） | 食べる、見る、出る |
| く/ぐ/す/む/ぶ/ぬ | 五段动词 | 書く、泳ぐ、話す、読む、遊ぶ、死ぬ |
| う/つ | 五段动词 | 買う、待つ |
| い/しい | 形容词 | 大きい、美しい |
| り/き/み/し/ち/け | 名词（连用形转名词） | 休み、働き、楽しみ |
| える | 一段动词（他动） | 上げる、決める |
| れる | 被动/可能/自发 | 見れる、起きれる |

九条规则，覆盖 42–44% 带送假名的实例。看见假名就知道词类——眼睛看到的，不需要记。

### 1.4 形态派生（不记）

同一个词根，通过系统性的后缀变化，衍生出动词、名词、形容词等不同词类。这是日语黏着语特性的直接体现。

举例：词根 **a-**（上）

```
上がる   a-garu   自动词 "上升"
上げる   a-geru   他动词 "抬起"
上がり   a-gari   名词   "上涨"
```

三个表面上的"(汉字,读法)对"，从形态角度看是一个词根。学一次词根 **a-**，剩下的派生形式通过你已经会的语法规则自动覆盖。

形态派生最密集的几个汉字：

| 汉字 | 表面"对"数 | 实际词根数 | 虚增 |
|------|----------|----------|------|
| 切 | 7 | 1 | 6 |
| 付 | 7 | 2 | 5 |
| 込 | 5 | 1 | 4 |
| 明 | 4 | 1 | 3 |
| 合 | 4 | 1 | 3 |
| 生 | 7 | 5 | 2 |

**切**有七个不同的露面形式——きる、きり、き、ぎる、ぎり、ぎ、ぎれる——但它们全部来自同一个词根。清浊交替（き↔ぎ）加上不同的活用/派生后缀，制造了七种表面形式。学一个词根，七个全收。

这一层再归并约 10.0%。比例不如活用形归并大，但它的重要性不在数字——在于让你意识到：**你一直在记的很多"项"，根本不应该作为独立项存在。**

## 第二章：判断层——音读还是训读（6条规则）

从这章开始，需要你主动做一点事。

看到一个带汉字的日语词，第一件事不是查字典，而是花一秒判断它是音读还是训读。不是为了猜对——最终你都会查字典确认——而是为了在脑内建立正确的分拣系统：音读走一条处理通路，训读走另一条。

六条规则，按优先级排：

| # | 规则 | 判断 | 准确率 | 累计覆盖 |
|---|------|------|--------|---------|
| 1 | 多汉字 + 无送假名 | 音读 | ~96% | 54–62% |
| 2 | 有送假名 | 训读 | ~90% | 80–85% |
| 3 | 单汉字 + 无假名 | 训读 | ~65% | 85–86% |
| 4 | 身体/自然/人相关语境 | 训读 | +35%信号 | ~89% |
| 5 | 入声尾(く/つ/ち/き)+无假名 | 音读 | ~80% | ~91% |
| 6 | 抽象/数量/情感相关语境 | 音读 | +60%信号 | ~91% |

规则 1 和 2 已经覆盖了 80–85%。加上规则 3 到 86%。后续规则的边际贡献递减，但它们的存在让整套规则覆盖到 91%——你知道剩下 9% 需要查字典，而不是茫然面对所有词。

使用示例：

```
電話      → 两个汉字，无假名 → 规则1：音读 ✓
食べる    → 一个汉字+假名 → 规则2：训读 ✓
水        → 单汉字，无假名 → 规则3：训读(70%). 自然类 → 规则4：倾向训读 ✓
本        → 单汉字，无假名 → 规则3猜训读. 非身体/自然类 → 不确认，查字典
```

**六条规则，需记六项。覆盖 91% 的 JLPT 词汇。**（前提是你认识这个词里的汉字，知道它的意思——这对你来说是已满足的条件。）

## 第三章：巧记层——按什么顺序学

从这一章开始谈你确实需要记的那些词根。数量跑不掉，但顺序可以大幅影响难度。

### 3.1 先高频，后低频

不是所有汉字同等重要：

N3 的 124 个汉字就覆盖了全部 N3 训读实例的一半。先学高频的，每一分钟投入的产出最大。

### 3.2 词干连带——学了「取=と」，就差不多会了「撮=と」

不同汉字可能共享完全相同的训读词干。「口」读「くち」，「朽」也读「くち」——两个完全不同的汉字，同一个训读。

先学了「口=くち」（N5），再遇到「朽=くち」（N1）时，你不是从零开始记一个全新的映射，而只是确认一下："朽的训读跟口一样，都是くち"。这个确认的成本远低于全新的记忆——大约是新记忆的 30%。

学得越多，这种连带效应越强：

| 级别 | 总对数量 | 享受连带的字 | 实际记忆量 | 蛮力记忆量 | 省力比例 |

| N5 | 400 | 1 | 328.6 | 400 | 17.8% |
| N4 | 417 | 3 | 335.8 | 417 | 19.5% |
| N3 | 616 | 10 | 481.6 | 616 | 21.8% |
| N2 | 671 | 10 | 521.2 | 671 | 22.3% |
| N1 | 824 | 23 | 651.8 | 824 | 20.9% |

到了 N1，有 23 个字因为和之前学过的字共享词干，记忆量直接打三折。

## 第四章：复利层——逐级递进，越学越快

如果你先学完 N5 的全部 400 对，再开始 N4——你会发现 N4 的 417 对中，有 **105 对（25%）在 N5 已经见过了**。它们不是新东西，是回头客。

逐级累积效应：

| 学到 | 累计掌握(对) | 其中新学 | 来自前级 | 复用率 |
|------|------------|---------|---------|--------|
| N5 完成 | 400 | 400 | 0 | 0% |
| N4 完成 | 712 | 312 | 105 | 25% |
| N3 完成 | 1,082 | 370 | 246 | 40% |
| N2 完成 | 1,438 | 356 | 315 | 47% |
| N1 完成 | 1,892 | 454 | 370 | 45% |

如果五个级别独立学——每级都从零开始——总和是 2,928 对。因为跨级复用，实际只需要 1,892 对。**复利效应帮你省了 1,036 对（35%）。**

这不是额外策略，是按 N5→N4→N3→N2→N1 的顺序递进的自然回报。各级别不是孤岛——你学到后面会发现，几乎一半的东西在前面已经见过了。

## 第六章：日常使用方法

这套东西在你每天实际遇到日语词时的运转方式：

```
看到词 →
│
├─ 多汉字 + 无假名？
│   → 音读。用中文近似音猜。✓
│
├─ 有送假名？
│   → 训读。进入训读处理：
│   │
│   ├─ 看送假名结尾 → 确定词类（不记，语法自带）
│   ├─ 是动词？查自他对应模式（不记，十个模式已学会）
│   │   看到～める → 自动词大概率～まる
│   │   看到～げる → 自动词大概率～がる
│   ├─ 提取词干 → 回想：以前见过这个词干吗？
│   │   见过 → 确认关联（连带效应，几乎不费力）
│   │   没见过 → 记词干（唯一需要做动作的地方）
│   └─ ✓
│
├─ 单汉字 + 无假名？
│   → 七成训读，三成音读。先猜训读。
│   │
│   ├─ 身体/自然类 → 更倾向训读
│   └─ 抽象/数字类 → 更倾向音读
│
└─ 查字典确认（始终是最后一步）
```

### 记词干时的优先级

1. **先记高频的**（按每级前 20–30 的列表走）
2. **记新词干时，回想有没有已经会的同词干字**（学「者=もの」时想"跟「物=もの」一样"）
3. **动词注意成对记**（学「上げる」时同步留意「上がる」）
4. **同一个汉字有多个训读时，先看它们之间的关系**（75%有规律：名词形/动词形、自/他、清浊变）
5. **具体域优先，抽象域后置**（身体/自然/动作对你零翻译成本，先拿下；抽象概念后碰）

### 复习时的原则

- 每学完一级，扫描下一级的词表——已认识的直接跳过
- 重点攻克"全新"那部分（每级约 300–450 对 → 归并后约 260–400 新词根）
- 活用形不用复习——词干会了，活用自动覆盖

本系统所有数字基于以下数据和分析：

**数据源**：

- **JLPT 词汇**：`kun_v9_data.json`——8,375 个 JLPT 词汇，逐字标注音读/训读分类。分类由规则+人工校对完成，总准确率 99.4%。
- **汉字数据库**：`kun_v8_reverse_index.json`——7,644 读法→汉字映射、200 词干→汉字聚类，每字附带部首、语义描述、JLPT 级别分布。
- **漢字検索 V2**：46,849 汉字的结构化数据——部首、部件、音训读、语义标注。
- **V9 诊断系统**：`kun_diagnostic_v9.py`——四维量化评估（压缩比、层级递进、锚点覆盖率、陷阱标记），所有数字可复现。

**已验证有效的发现（10 项）**：

1. 音训判断规则：6 条，覆盖 91% JLPT 词汇
2. 自他对应系统：10 个模式，覆盖 2.7–11.9%/级（V9 检测到 73 对跨汉字自他，为下限值——因 V9 存储词干不含送假名后缀，完整读法下覆盖更高）
3. 送假名词类规则：9 条，覆盖 40–44% 带假名实例
4. 帕累托频率优先：前 124 字覆盖 N3 的 50%
5. 词干连带效应：共享词干的后续字记忆量降为 30–70%（3 层：强 2 拍共享 465 词根省 70%、中 1 拍同域 249 词根省 50%、弱 1 拍高频 552 词根省 30%）
6. 跨级复利效应：逐级递进，25–47% 复用率（N4=25.2%, N3=39.9%, N2=46.9%, N1=44.9%）
7. 活用形归并：56.2% 表面实例为活用变体（N1 最高 38%，N5 最低 23%——高级词汇活用形式更多样）
8. 形态派生归并：5 步算法归并 10.0%（清浊交替、自他对、词干+后缀剥离、同首拍、同首 2 拍）
9. 部首锚点分层：97.3% 对可归入部首群，强部首层（≥10 JLPT 成员）覆盖 1229 对（65%），中（5–9）350 对，弱（2–4）262 对
10. 陷阱全标记：90 多训字 + 123 同音异字 + 70 形近异训（有意义部首级，排除笔画级）+ 29 重度陷阱

**已验证的否定发现（5 项）**：

1. **形近字极少共享读法**（0.2–0.6%）→ "训读声旁"概念不成立
2. **部首对读法的互信息不足以支撑预测** → 不能靠部首猜训读
3. **语义域对读法的约束力微弱**（域内 Shannon 熵 5–7 bits）→ 知道语义不能预测读法
4. **ML 聚类未发现人类遗漏的深层结构** → 30+ 维特征空间中，聚类由表层音韵特征驱动
5. **送假名→读法末元音预测力极弱**（N2 级别 0 个强预测）→ 假名不能告诉你读法结尾是什么

这些否定发现的重要性不亚于肯定发现——它们告诉你**什么路走不通**，帮你省下走冤枉路的时间。

**统计方法**：

- 活用形归并：对(汉字, GT读法)去重，不论活用变体
- 形态聚类：同汉字不同读法，通过清浊交替、后缀剥离、共享首拍等规则归并为词根
- 跨级累积：计算每级在前级已出现的(汉字,读法)对比例
- 词干连带：共享词干的汉字，学习权重从 1.0 降为 0.3（基于认知心理学中类比迁移的证据）
- 帕累托排序：按(汉字,读法)对的 JLPT 出现频率降序
- 互信息：标准 Shannon 熵，特征与读法之间的信息量
- K-means 聚类：30+ 维特征向量，标准化欧氏距离，k=12

## 附录 D：常见误区

**1. 把音读当成训读。**
「電話」有两个汉字没有假名 → 不是训读，是音读（でんわ ≈ dianhua）。多汉字无假名，默认音读。

**2. 把训读当成音读。**
「食べる」有送假名「べる」→ 一定是训读。送假名是训读的硬信号。

**3. 单汉字词是模糊区。**
「本」可以是音读（ほん，如「日本」）也可以是训读（もと，如「元」的训读）——但「本」和「元」是不同的字。单汉字无假名时，70% 可能是训读，但不确认时需要查字典。

**4. 入声尾是音读强信号但不绝对。**
「楽」（がく）是音读，「学」（がく）也是。但「足」可以音读（そく）也可以训读（あし）——同一个字两个读法，靠语境区分。

**5. 自他对应模式是概率性的。**
大多数～まる/～める 是自他对，但具体的配对关系需要确认。模式给了你正确的预期方向，最后一步始终是查字典。
