## 3. 部首误导

- **手部** → 你以为都是动词 → 但手紙(てがみ)=名词——手部也有名词
- **心部** → 你以为都是心理动词 → 但心(こころ)=名词——心部名词也不少
- **日部** → 你以为都是时间 → 但日(ひ)=名词/量词——日部名词占多数
- **口部** → 你以为都是口部动作 → 但口(くち)=名词——口部49.6%动词/37.6%名词→混合
