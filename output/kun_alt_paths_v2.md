## 综合发现

### 有实际价值的杠杆（新增）

1. **跨级复用率很高**：N5→N4的汉字复用读法率68.6%，N4→N3为66.9%。按级别递进学习有显著的累积效应。

2. **帕累托极度集中**：N3的124个汉字覆盖50% kun实例，339个汉字覆盖80%。高频字战略价值极高。

3. **自他系统是一个可教的语法点**：N3有57对，覆盖9.5%。10个模式学会后，所有动词对自动推导。

4. **互信息证实了"没有单个强特征"**：读法总熵8.09 bits，最强的特征（部首）也只能解释其中极小部分。多特征组合也没有显著改善。

5. **形近字极少共享读法**：N3中1581对形近字，仅0.6%共享读法。形声字的"声旁"概念在训读中不成立。

### 最终路径架构建议

```
Layer 0 (零成本，语法意识):
  ├── 自他动词系统 (10个模式，学会后自动推导所有对)
  └── 送假名词类系统 (B规则，100%准确)

Layer 1 (成本~6，音训判断):
  └── A规则 (91%覆盖，6条规则)

Layer 2 (成本~20-50，高频字优先+网络传播):
  ├── 帕累托优先：先学覆盖50%实例的那几十个高频字
  └── 共享词干折扣：邻字成本从1降到0.3

Layer 3 (跨级复用):
  ├── N5学过的汉字到N4复用率~60%
  └── 每级别的"新学量"比独立学习减少30-40%

Layer 4 (剩余死记，优化顺序):
  ├── 按反向聚类（多字共享一个读法的优先）
  ├── 按频率排序（高频词干优先）
  └── 具体域优先（汉语者语义透明）→ 抽象域后学
```
