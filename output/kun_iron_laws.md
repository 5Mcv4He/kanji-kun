# Kun-Yomi 铁律 (Iron Laws)

训读领域的绝对规律 — 接近100%准确率，零或极低记忆成本。

| # | 铁律 | 预测 | 类型 |
|---|------|------|------|
| A1 | 有送假名→训读 | kun | Type A |
| A2 | 单汉字无假名→训读 | kun | Type A |
| A3 | 多汉字无假名→音读 | on | Type A |
| A4 | 身体/自然/人域→训读 | kun | Type A |
| D1 | 浊音不重复(同一词干内) | verify:no_voiced_repeat | Type D |
| D2 | 促音只在入声字后 | verify:entering_only | Type D |
| D4 | 训读动词必有送假名 | verify:verb_has_okuri | Type D |

## 与 kanji-on 五鉄則 对比

| kanji-on | kun-yomi 对应 |
|----------|-------------|
| 1. 同声旁=同音读 | A4: 同语义域=同读法 |
| 2. 拼音→音读映射 | A1: 送假名→训读用言 |
| 3. 入声=短音 | D1: 浊音不重复(训读验证) |
| 4. 词频默认=93% | A3: 多汉字无假名=音读 |
| 5. 复合词位置消歧 | A2: 单汉字词=训读 |
