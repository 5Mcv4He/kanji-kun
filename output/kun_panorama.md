## 地图1：训读在哪里出现？（生存空间）

JLPT词汇中，训读出现在以下结构环境中：

```
                      JLPT训读的生存空间
         ┌─────────────────────────────────────────┐
         │                                         │
    单汉字词                复合词中的训读位置
    (2,158例, 50%)         (2,131例, 50%)
         │                    │
    ┌────┴────┐         ┌────┼────────┐
    │         │         │    │        │
  有送假名  无送假名   词首  词中    词尾
  (919例)  (1,239例)  (1,219) (36)  (766)
   43%       57%       57%    2%    36%
```

**关键认知：**

1. **单汉字无送假名 = 训读的大本营**（1,239例）。这类词包括：愛、年、時、音、雨、風、山、川、手、目、耳、口、心、花、春、夏、秋、冬... 基本都是基本词汇。这不需要规则——你看到一个孤零零的汉字，90%概率是训读。

2. **复合词首位的训读**（1,219例）：当一个复合词的第一个字是训读时，它要么是"训+音"（重箱読み，如 台所=だいどころ），要么是"训+训"（602例）。注意：训读在复合词首位时，它的送假名往往被省略（如 受付=うけつけ，不是 受け付け）。

3. **复合词末位的训读**（766例）：最典型的场景是"音+训"（湯桶読み）。这类词中的训读几乎总是名词性的、无送假名的词干形式。

### 密码本的规律

**自动词/他动词配对密码：**
```
〜まる/〜める  →  自/他（止まる/止める、閉まる/閉める）
〜がる/〜げる  →  自/他（上がる/上げる、下がる/下げる）
〜れる/〜る    →  自/他（切れる/切る、売れる/売る）
〜く/〜す      →  自/他（付く/付す、抜く/抜す）
```

**形容词密码：**
```
〜い      →  形容词终止形（大きい、重い、軽い）
〜しい    →  形容词（正しい、苦しい、難しい）
〜かい    →  形容词（細かい、暖かい）
〜ない    →  否定形容词（危ない、少ない）
```

**名词化密码：**
```
〜り/〜き/〜み/〜し/〜ち/〜け  →  连用形名词化
```

### 多训字如何消歧？

**方法1：送假名直接告诉你（89%准确）**

这是最可靠的信号。看到送假名，词干就确定了：
```
生+きる → いきる   生+まれる → うまれる
生+える → はえる   生（单独）→ なま
```

训读最多的汉字之所以"多"，正是因为它们搭配了不同的送假名。本质上不是"一个汉字有7种读法"，而是"一个汉字与7种不同的后缀组合"。

**方法2：无语境时用最高频的那个（90%准确）**

当一个多训字没有送假名时（词尾或单汉字词），90%的情况下最高频的训读就是正确答案。这不是规则，但刷题过程中自然习得。

### 多训字的隐藏规律

多训字中，不同训读之间往往有**语义/语法关联**——不是随机的：

1. **自他对应**：止(とまる/とめる)、付(つく/つける)、切(きれる/きる)
2. **具体/抽象**：上(うえ/あがる)、下(した/さがる)
3. **名词/动词**：空(そら/あく)、休(やすみ/やすむ)
4. **清浊对立（连浊来源）**：切(きる/ぎれる)、付(つく/づく)、取(とる/どる)

- 如果你的中文知识告诉你这个字是**身体部位/自然物/动物/植物/亲属称谓/方位** → 大概率是训读，大概率是名词

## 地图5：训训复合词中的连浊

602个纯训读复合词中，只有9%发生连浊。但这9%集中在特定模式：

### 连浊高发模式

连浊最常发生在以下场景：

1. **动作+动作 → 复合动词**：付く(つく)+合う(あう)→付合う(つきあう, 无连浊) ... 等等，这个例子本身没连浊。但模式是存在的。

2. **名词+名词 → 复合名词（修饰关系）**：
   ```
   青(あお)+空(そら)→青空(あおぞら) [そ→ぞ]
   足(あし)+音(おと)→足音(あしおと) [无连浊]
   ```

3. **动词连用形+动词连用形 → 名词**：
   ```
   後(あと)+片(かた)+付(つ)→後片付け(あとかたづけ) [つ→づ]
   ```

### 为什么连浊不可预测？

连浊的触发条件涉及多种因素：
- 语义关系（修饰vs并列）
- 语音环境（Lyman's Law：第二个词干内已有浊音则阻塞）
- 词汇化程度（高频词更容易连浊）
- 历史来源

**对学习者：** 不需要预测连浊。当你推导的词干（如 あおそら）和实际读音（あおぞら）差了一个浊音，你知道只是连浊——词干没错。这足够了。

### 部件训读的局限

1. **覆盖率低**：JLPT中仅约5-7%的训读可以通过部件推导
2. **准确率不高**：即使是召→て，准确率也只有38%
3. **大部分是偶然重合**：共享笔画的字不一定共享词源

### 对学习者的真正价值

不是"记住这个部件→那个词干"，而是**当你遇到一个不认识训读的汉字时，看看它的部件，有没有和你认识的某个汉字共享部件？如果有，大胆猜测它们共享训读词干，然后在实际阅读中验证。**

这是一种**主动学习策略**，不是一条规则。

## 冷启动全景（零记忆，纯推导）

一个完全零基础的汉语母语者，不靠任何日语记忆，能用什么？

| 信号 | 可推导率 | 学习成本 |
|------|---------|---------|
| 单汉字无假名 → 训读 | 触发条件100% | 1秒 |
| 有送假名 → 训读动词/形容词 | 触发条件96% | 1秒 |
| 身体/自然/亲属字 → 训读名词 | 触发条件~85% | 中文知识 |
| 送假名→词干（查密码本） | 覆盖35%条目，准确率待验证 | 5分钟查表 |
| 抽象/文化/政治字 → 音读 | 触发条件~80% | 中文知识 |
| 部件→训读词干 | 覆盖5-7%条目 | 10分钟了解20个高频家族 |

**冷启动推理流程：**
```
1. 看字 → 中文知识判断语义域
   ├─ 基本词汇(身体/自然/动作) → 大概率训读
   └─ 抽象词汇(社会/经济/文化) → 大概率音读
   
2. 看形态
   ├─ 有送假名 → 训读动词/形容词 → 查密码本找词干
   ├─ 单汉字无假名 → 大概率训读名词 → 需要记忆
   └─ 多汉字无假名 → 大概率音读 → 去查音读推导规则

3. 交叉验证
   ├─ 认出声旁？ → 对其他同声旁字的知识
   ├─ 认出部件？ → 回想同部件字的训读
   └─ 看到送假名？ → 匹配密码本
```

## 训读全景总结

训读不是音读那样的规则系统。它是一张**关联网络**：

```
            ┌──────────────────┐
            │   语义域判断     │ ← 中文知识，免费
            │  身体/自然/动作  │
            └───────┬──────────┘
                    ↓
            ┌──────────────────┐
            │   形态判断       │ ← 送假名、位置
            │  有假名=训读    │
            └───────┬──────────┘
                    ↓
         ┌──────────┼──────────┐
         ↓          ↓          ↓
    ┌────────┐ ┌────────┐ ┌────────┐
    │送假名  │ │部件家族│ │词频默认│
    │密码本  │ │暗号    │ │(自然   │
    │244种   │ │20+家族 │ │ 习得)  │
    └───┬────┘ └───┬────┘ └───┬────┘
        └──────────┼──────────┘
                   ↓
            ┌──────────────────┐
            │   表面调整       │
            │  连浊 + 促音     │
            └──────────────────┘
```

**记忆量核算：**
- 密码本244条中，高频（≥20次）的仅20条 → 看3遍就记住
- 部件家族中，高频可信（≥4字）的仅10个 → 过一遍就记住
- 词频默认 → 不需要背，刷题自然习得
- 连浊 → 不需要记具体词，知道现象存在即可

**真正需要死记的训读：**
- 熟字训 ~15个（明日=あした、大人=おとな...）
- 极不规则多训字 ~30个（生、付、切等7变体怪物）
- 其余全部可以通过信号组合推导 + 刷题自然吸收
