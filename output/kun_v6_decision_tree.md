# 训读判定决策树 · Kun-Yomi Decision Tree

> 不是记100条规则，而是走一个流程
> 每次遇到汉字 → 回答1-3个问题 → 得到判定 + 置信度

---

## 主决策流程

```
看到含汉字的日语词
│
├─ 单独一个汉字？
│   ├─ 是 → [训读 82.7%]
│   │   ├─ 有送假名？ → 是 → [训读用言 96.1%]
│   │   │   ├─ 尾音=る/う/く/つ/ぶ/む/ぐ/ぬ → 五段动词 [100%]
│   │   │   ├─ 尾音=す → 五段他动词 [100%]
│   │   │   ├─ 尾音=える/ける/いる → 一段动词 [100%]
│   │   │   └─ 尾音=い/しい → 形容词 [100%]
│   │   └─ 无送假名 → [名词 72.2%]
│   │       ├─ 部首=魚/米/牛/竹/虫/木/雨 → 几乎确认名词 [95%+]
│   │       └─ 部首=手/言/力/足/刀 → 也有动词可能 [65%]
│   └─ 否 → 复合词
│       ├─ 2汉字2拍 → 音读+音读 [71.2%]
│       ├─ 2汉字5拍+ → 含训读 [90.4%]
│       └─ 3拍 → 看具体情况
```

---

## 验证层（交叉确认）

| 验证规则 | 用法 | 准确率 |
|---------|------|--------|
| 浊音g/z/d/b不重复 | 排除包含重复浊音的训读猜测 | 99.5% |
| 自然物部首无动词 | 魚/米/牛/竹/虫/雨部 → 排除动词训读 | 95% |
| 入声字→动词倾向 | -ク/-ツ音读字 → 训读倾向动词 | 64% |
