# 训读学习系统 · 使用手册

## 当你看到一个带汉字的日语词，脑内执行以下流程：

```
看到词 → 启动判断
│
├─ 词里有多个汉字，且没有送假名？
│   → 99%是音读。用中文近似发音猜。✓ 结束
│   例：電話(でんわ)、学校(がっこう)、図書館(としょかん)
│
├─ 词里有送假名（汉字后面挂着假名）？
│   → 99%是训读。进入「训读处理流程」
│   例：食べる、大きい、走る
│
├─ 词里只有一个汉字，没有假名？
│   → 70%是训读，30%是音读。先猜训读。
│   例：水(みず)、山(やま) ←训；　本(ほん)、一(いち) ←音
│
├─ 词的语义是身体部位/自然物/人？
│   → 更倾向于训读
│   例：目(め)、耳(みみ)、雨(あめ)、親(おや)
│
└─ 词的语义是抽象概念/数字/情感？
    → 更倾向于音读
    例：愛(あい)、数(すう)、自由(じゆう)
```

## 训读处理流程（确定是训读之后）

```
确定是训读
│
├─ STEP 1: 看送假名 → 定词类（免费，零记忆成本）
│   │
│   ├─ 送假名是 る → 动词（一段/五段）
│   │   例：食べる、見る、出る
│   │
│   ├─ 送假名是 く/ぐ/す/む/ぶ/ぬ → 动词（五段）
│   │   例：書く、泳ぐ、話す、読む、遊ぶ、死ぬ
│   │
│   ├─ 送假名是 う/つ → 动词（五段）
│   │   例：買う、待つ
│   │
│   ├─ 送假名是 い/しい → 形容词
│   │   例：大きい、美しい
│   │
│   ├─ 送假名是 り/き/み/し/ち/け → 名词（连用形转名词）
│   │   例：休み、働き、楽しみ、話し、勝ち、負け
│   │
│   ├─ 送假名是 える → 一段动词（他动）
│   │   例：上げる、決める
│   │
│   └─ 送假名是 れる → 被动/可能/自发
│       例：見れる、起きれる
│
├─ STEP 2: 检查自他对（免费，零记忆成本）
│   │
│   │  如果这动词有自动词/他动词配对：
│   │  ├─ ～まる↔～める：高まる↔高める、集まる↔集める、強まる↔強める
│   │  ├─ ～がる↔～げる：上がる↔上げる、下がる↔下げる
│   │  ├─ ～く↔～ける：開く↔開ける、届く↔届ける、続く↔続ける
│   │  ├─ ～る↔～す：出る↔出す、直る↔直す、通る↔通す
│   │  ├─ ～れる↔～る：切れる↔切る、売れる↔売る
│   │  ├─ ～かる↔～ける：助かる↔助ける、掛かる↔掛ける
│   │  ├─ ～う↔～える：変わる↔変える、伝わる↔伝える
│   │  ├─ ～つ↔～てる：立つ↔立てる
│   │  ├─ ～ぶ↔～べる：並ぶ↔並べる
│   │  └─ ～む↔～める：止む↔止める、縮む↔縮める
│   │
│   │  学会这个模式 = 自动识别所有对，不需要一对对记。
│   │
│   └─ 如果没有任何规则覆盖 → 进入「需要记忆」
│
└─ STEP 3: 词干是否与已学汉字共享？
    │
    │  已学过「日=ひ」→ 遇到「火=ひ」成本降到0.3
    │  已学过「取=と」→ 遇到「撮=と」成本降到0.3
    │  已学过「物=もの」→ 遇到「者=もの」成本降到0.3
    │
    │  这是按帕累托顺序学习的自然收益。
    └─ 如果连共享都没有 → 硬记，但已经很少了
```

## 实操：按级别的最优学习顺序

### 在开始背任何单词之前，先掌握以下永久资产：

**资产1：6条音训判断规则（5分钟）**

| # | 规则 | 判断为 | 准确率 |
|---|------|--------|--------|
| 1 | 多汉字 + 无假名 | 音读 | ~96% |
| 2 | 有送假名 | 训读 | ~90% |
| 3 | 单汉字 + 无假名 | 训读 | ~65% |
| 4 | 汉字在身体/自然/人相关语境 | 训读 | ~35% |
| 5 | 汉字在抽象/数量/情感语境 | 音读 | ~60% |
| 6 | 音读以 く/つ/ち/き 结尾 + 无假名 | 音读 | ~80% |

应用顺序：1→2→3→4→6→5（按累计覆盖率从高到低）

**资产2：10个自他动词模式（10分钟）**

记住这10个对应关系，终身受用：まる↔める / がる↔げる / く↔ける / る↔す / れる↔る / かる↔ける / う↔える / つ↔てる / ぶ↔べる / む↔める

**资产3：9条送假名词类规则（5分钟）**

见上方 STEP 1。

**总计：20分钟终身投资。** 这20分钟让你之后的每一个日语词都有明确的处理路径。

## 日常学习工作流

### 遇到新词时：

```
1. 看一眼 → 多汉字无假名？ → 音读，跳过（中文近似）
2. 有送假名？ → 训读
   ├─ 先看送假名确定词类（不需要记，看假名就知道）
   ├─ 是动词？检查有无自他对（看送假名结尾模式）
   │   看到～める → 自动词大概率是～まる
   │   看到～げる → 自动词大概率是～がる
   │   看到～ける → 自动词大概率是～く 或 ～かる
   │   看到～す   → 自动词大概率是～る
   └─ 词干本身需要记（但这是唯一需要记的东西）
3. 单汉字无假名？ → 先猜训读
   └─ 身体/自然类 → 更可能是训读
   └─ 抽象/数字类 → 更可能是音读
```

### 背词时的优先级：

1. **先背高频字**（上面列的顺序）
2. **背新词干时，回想有没有已经会的同词干字**（如学「者=もの」时回想「物=もの」）
3. **动词注意配对**（学「上げる」时，留意自动词是「上がる」）
4. **同一个汉字的多个训读，注意它们的关系**（75%是有规律的：名词形/动词形、自/他、浊音变）
5. **具体域优先**（身体部位、自然物、具体动作对汉语者更直观，先学）
6. **抽象域后学**（数量、情感、品质——需要额外建立语义映射）

### 复习时：

- 每学完一个级别，做一次"跨级扫雷"——看看新级别有哪些已经在旧级别学过了
- 已经认识的(汉字,词干)对 → 快速过一遍即可
- 重点攻克"全新"的那部分（每级约300-450对）
- 活用形是免费的——学会「書=か」之后，書く/書きます/書いて/書いた 全部自动覆盖

## 常见陷阱

1. **不要把音读误判为训读**
   「電話」看起来有两个汉字但没有假名 → 不是训读，是音读（でんわ ≈ "dianhua"）
   
2. **不要把训读误判为音读**  
   「食べる」有送假名「べる」→ 一定是训读（たべる 不是中文近似音）

3. **单汉字词是模糊地带**
   「本」可能是音读(ほん)也可能是训读(もと)，取决于上下文
   → 音读场景：「日本」(にほん)
   → 训读场景：「本の虫」(ほんのむし) 里的「本」是训读... 不，这里ほん也是音读
   → 真正的训读：「元」(もと)  ← 注意「本」和「元」是不同的字

4. **「入声字」是音读的强信号但不是绝对的**
   「楽」(がく) 是音读，「学」(がく) 也是音读
   但「足」(そく→音) vs 足(あし→训) — 同字不同读

5. **自他动词对的模式是概率性的，不是绝对的**
   大多数～まる/～める 是自他对，但「決める」对应的自动词是「決まる」，不是「決かる」
   → 模式给了你正确的预期方向，具体是哪一种需要确认
