# JLPT汉字读音推导 · 完整操作流程

看到任何一个日语单词，按以下步骤操作。每步都有准确率标注，遇到不确定时知道该信哪个信号。

---

## 总览

```
单词 → [1]音/训判断 → [2]音读推导 / [3]训读推导 → [4]调整(促音+连浊) → 最终读音
        99.4%准确         95.1%准确    94.4%准确
```

---

## 第1步：判断每个汉字是音读还是训读（3秒）

看一眼单词形态，立刻判断：

```
单词含假名（送假名）？
  ├─ 是 → 那个汉字是训读。例如：食べる(食=训)、大きい(大=训)、歩く(歩=训)
  │       准确率 96%
  │       例外极少：場合(ばあい、音+训)、真面目(まじめ、熟字训)
  │
  └─ 否 → 继续判断：
          单汉字无假名？
            ├─ 是 → 大概率训读。例如：愛(あい)、年(とし)、時(とき)
            │       准确率 84%。例外：数词(一=いち)、单位(円=えん)
            │
            └─ 否 → 多汉字无假名 → 音读。
                    例如：安心(あんしん)、東京(とうきょう)、消火器(しょうかき)
                    准确率 90%+
                    例外：熟字训(明日=あした)、重箱読み(台所=だいどころ)
```

**判断完，给每个汉字打标签：[音] 或 [训]。**

如果全标完了且全是音读或全是训读，直接跳到第2步或第3步。如果有音有训（混合词），分开处理。

---

## 第2步：音读汉字 → 推导具体读音

对于每个标记为[音]的汉字，按以下信号优先级推导：

### 信号A（最强）：JLPT词频默认音读 — 93%准确

> 这个汉字在JLPT词汇里最常出现的那个音读，93%情况下就是正确的。

**操作**：回想你刷红宝书/做题时见过这个汉字最多的那个读音。大脑自动有这个能力。

```
例：消 → 你见过 消化(しょうか)、消防(しょうぼう)、解消(かいしょう)
          → 默认 = ショウ ✓
例：食 → 你见过 食堂(しょくどう)、食事(しょくじ)、食品(しょくひん)
          → 默认 = ショク ✓
例：人 → 你见过 人口(じんこう)、人間(にんげん)、大人(おとな)
          → 有两个常见音读！默认取哪个？
          → じん 出现更频繁 → 默认 = ジン
            但注意：这个字是多音字，需要信号E辅助
```

**如果你完全没见过这个汉字**，或者不确定 → 跳到信号B。

> 形声字的声旁（声符）决定音读。同声旁的汉字音读相同。

**操作**：认出这个汉字的声旁 → 回想这个声旁的其他汉字的音读。

### 信号D（强）：入声约束 — 约95%

> 入声字（中古汉语以 -p, -t, -k 结尾）的音读必定是短音（1-2拍），必定以 く・つ・ち・き・う・い 结尾。**不可能以长音（ー/う）结尾。**

**操作**：从普通话读音判断是不是入声字。

```
判断规则（10秒）：
  普通话韵尾是 -n 或 -ng？ → 不是入声，跳过
  普通话韵母是 ai/ei/ao/ou/iu/ui/er？ → 不是入声，跳过
  其他情况 → 大概率是入声！

入声字 → 音读约束：
  结尾必定是：く・つ・ち・き・う・い 之一
  长度必定是：1-2拍（不可能3拍以上）
  不可能以长音（ー/う）结尾
```

```
例：六 → 普通话 liù
         → 韵母是 iu → 跳过（复元音韵母，不是入声）
         → 等等，六 其实是入声字！（MC *ljuwk, -k入声）
         → 这是规则的例外情况... 实际上 liu 韵母需要单独判断
         
更可靠的判断方式——记住常见入声字：
  一(イチ) 六(ロク) 七(シチ) 八(ハチ) 十(ジュウ)
  百(ヒャク) 北(ホク) 国(コク) 学(ガク) 食(ショク)
  発(ハツ) 熱(ネツ) 物(ブツ) 圧(アツ) 決(ケツ)
  式(シキ) 的(テキ) 歴(レキ) 積(セキ)

例：学 → 入声字 → 音读必须是短音，结尾く/つ/ち/き/う/い
         → 信号A建议：ガク（2拍，结尾く）✓
         → 如果信号B建议了ガコウ（3拍，长音），则被入声约束否决
```

**入声约束的主要用途是排除错误答案**，而不是直接给出答案。

### 信号E（中等）：多音字语境消歧 — 81%精确

> 多音字在复合词中的位置影响读音选择。同一个字在词首/词尾可能读不同音。

**操作**：如果这是一个多音字（有多个音读），考虑其位置。

```
多音字位置优先级：

  在词首位置：
    人 → じん（人口、人生）/ にん（人間、人形）
    上 → じょう（上手、上下）/ しょう（—）

  在词尾位置：
    人 → じん（外国人）/ にん（人间、人数、人気）
    日 → にち（毎日）/ か（三日）/ び（曜日）
    分 → ぶん（十分）/ ふん（三分、十分=じゅっぷん）
    切 → せつ（切断）/ さい（一切、大切）

  促音化特殊语境：
    一 + か/さ/た/は行 → いっ（一切=いっさい、一所=いっしょ）
    一 + 其他 → いち（一時=いちじ、一本=いっぽん）
```

```
例：一切 → 一 + 切
         → 一：词首 + 后接さ行 → いっ（促音化）✓
         → 切：词尾 + 跟在「一」后 → さい ✓
         → 最终：いっさい ✓

例：人間 → 人 + 間
         → 人：词首 + 特殊词（人間是固定词）→ にん ✓
         → 間：词尾 → げん ✓
         → 最终：にんげん ✓
```

### 信号优先级汇总

当你同时有多个信号时，按以下顺序决策：

```
1. 入声约束（信号D）：先排除不可能答案
2. JLPT词频默认（信号A）：93%准确，最强
3. 多音字语境（信号E）：如果信号A给出多音字，用位置信息调整
4. 拼音映射（信号B）：信号A不确定时使用
5. 声旁（信号C）：补充验证

如果信号A+B一致 → 确信度极高（>95%）
如果信号A+B+C三者一致 → 几乎100%正确
如果信号A和B冲突 → 优先信A（词频93% > 拼音46%）
```

## 第3步：训读汉字 → 推导具体读音

对于每个标记为[训]的汉字：

### 信号A（强）：JLPT词频默认训读 — 82%准确

> 和音读一样，每个汉字在JLPT里最常出现的那个训读，82%情况下就是正确答案。

**操作**：回想你见过的这个汉字最常见的训读。

```
例：食 → 训读有 た(食べる)、く(食う)
         → 食べる 比 食う 常见得多
         → 信号A建议：た ✓

例：大 → 训读有 おお(大きい)、おお(大きな)
         → 信号A建议：おお ✓
```

### 信号B（强）：送假名语境消歧 — 87%精确

> 对于多训字，后面跟着的假名直接告诉你是哪个训读。

**操作**：看汉字后面跟的假名 → 匹配训读。

这个规则几乎不需要"学"——你在阅读中自然就会：

```
生 + きる → いきる
生 + まれる → うまれる
生 + える → はえる
生（单独）→ なま

受 + ける → うける
受 + かる → うかる
受（单独）→ うけ

出 + る → でる
出 + す → だす
出（单独）→ で
```

**关键领悟**：你不需要记住"生有5种训读"然后选。你看到「生きる」就知道是「い」，看到「生まれる」就知道是「う」。语感自动匹配。

## 第4步：表面音调整（读完即用）

前面推导出了每个汉字的"底层读音"，但实际发音可能有表面变化。

### 4a：促音化（っ）

> 入声字的 つ/ち/く/き 结尾，遇到下一个汉字以清辅音（k/s/t/h行）开头时，变成 っ。

```
规则：
  前字以「つ/ち」结尾 + 后字以 k/s/t/h 行开头 → つ/ち → っ
  前字以「く/き」结尾 + 后字以 k 行开头 → く/き → っ

例：発(ハツ) + 展(テン) → ハッテン（つ→っ）
例：学(ガク) + 校(コウ) → ガッコウ（く→っ）
例：一(イチ) + 切(サイ) → イッサイ（ち→っ）
例：食(ショク) + 器(キ) → ショッキ（く→っ）

不触发的情况：
  気(キ) + 候(コウ) → キコウ（気不是入声字，虽然结尾是き）
  地(チ) + 球(キュウ) → チキュウ（地不是入声字，虽然结尾是ち）

简单记忆：促音化只发生在入声字身上。
```

### 4b：连浊（゛）

> 复合词中，第二个字及以后的首音可能由清变浊。

```
规则：
  k→g (か→が、き→ぎ、く→ぐ、け→げ、こ→ご)
  s→z (さ→ざ、し→じ、す→ず、せ→ぜ、そ→ぞ)
  t→d (た→だ、ち→ぢ、つ→づ、て→で、と→ど)
  h→b (は→ば、ひ→び、ふ→ぶ、へ→べ、ほ→ぼ)

例：手(て) + 紙(かみ) → てがみ（か→が）
例：花(はな) + 火(び) → はなび（ひ→び）
例：酒(さけ) + 屋(や) → さかや → いざかや（居+酒→さ→ざ）

例外很多，不需要记特定词。策略：
  你推导出「てかみ」，实际听到「てがみ」→ 知道是连浊，词干没错
  你推导出「いさかや」，实际是「いざかや」→ 知道是连浊
  
  关键：词干（汉字的核心读音）推导对了，连浊只是表面音变。
```

## 完整操作示例

### 示例1：「消火器」N3（4秒完成）

```
Step 1 — 判断类型：
  三汉字无假名 → 全音读 ✓（1秒）

Step 2 — 音读推导：
  消：
    信号A（词频）：ショウ（消化、消防...）✓
    信号C（声旁）：「肖」→ショウ ✓
    双信号一致，确信度极高
  火：
    信号A（词频）：カ（火事、火曜日...）✓
    这是单音字，不会错
  器：
    信号A（词频）：キ（機器、器械...）✓
    信号D（入声）：普通话 qì → 不是入声 → 无约束

Step 4 — 调整：
  促音化：ショウ + カ + キ → 无促音条件（没有入声字つ/ち/く/き结尾）
  连浊：  カ → 无变化

最终：ショウ カ キ → しょうかき ✓ 完全命中
```

### 示例2：「受け継ぐ」N1（5秒完成）

```
Step 1 — 判断类型：
  有送假名「け」「ぐ」→ 训读复合词

Step 3 — 训读推导：
  受：
    信号A（词频）：う（受ける、受け取る...）
    信号B（语境）：后接「け」→ うけ ✓
  継：
    信号A（词频）：つ（継ぐ、受け継ぐ...）
    信号B（语境）：后接「ぐ」→ つ ✓

Step 4 — 调整：
  促音化：不适用（训读不促音化）
  连浊：つ + 浊化？实际 つぐ = 未浊化（原形就是つぐ）

最终：うけ つぐ → うけつぐ ✓ 完全命中
```

### 示例3：「一切」N3（需要语境知识）

```
Step 1 — 判断类型：
  两汉字无假名 → 音+音

Step 2 — 音读推导：
  一：
    信号A（词频）：イチ
    信号E（语境）：词首 + 后接さ行（切=サイ/セツ）→ 促音化 → イッ ✓
  切：
    信号A（词频）：セツ（切断、切実...）
    信号E（语境）：词尾 + 跟在「一」后 → サイ ✓
    这是多音字语境消歧（信号E）的关键案例

Step 4 — 调整：
  促音化：イチ + サイ → イッサイ（ち→っ）✓
  连浊：不适用

最终：イッ サイ → いっさい ✓
```

### 示例4：「明日」N5（完全不可推导，纯熟字训）

```
Step 1 — 判断类型：
  两汉字无假名 → 按规则判断为音+音
  实际：熟字训，整词读「あした」

所有四层信号全部失效：
  → 信号A：明=メイ、日=ニチ → めいにち ✗（实际 あした）
  → 信号B：明=míng→メイ、日=rì→ニチ → めいにち ✗
  → 信号C：声旁不适用
  → 信号D：不适用

这是纯例外，JLPT全范围只有约15个这样的词。直接背。
```

## 使用建议

**第一阶段（前30天）**：只练第1步和第2步信号A
- 看到单词 → 判断音读/训读
- 音读用最常见的读音 → 已经能对80%
- 训读看送假名 → 自动匹配

**第二阶段（30-90天）**：加入第2步信号B和信号D
- 遇到不认识的字用拼音推导
- 用入声约束排除不可能选项
- 命中率提到90%+

**第三阶段（90天+）**：加入第2步信号C/E和第3步信号B
- 形声字声旁变成直觉
- 多音字语境自动感知
- 多训字送假名变成条件反射
- 命中率95%，接近规律推导天花板
