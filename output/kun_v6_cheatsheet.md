## 排除器（验证用）

- **浊音不重复**：训读词干内g/z/d/b不重复出现 → 排除含重复浊音的猜测
- **自然物部首无动词**：魚/米/牛/竹/虫/雨部 → 绝无动词训读
- **入声字倾向动词**：音读-ク/-ツ的汉字 → 训读更可能是动词

## 记忆口诀

1. **有假名 = 训读**（单汉字+送假名=训读用言）
2. **无假名 = 名词**（单汉字无送假名=名词训读或音读名词）
3. **鱼虫木竹 = 名词**（自然物部首=实物名词）
4. **手言力足 = 动词**（动作部首=动词训读）
5. **2拍双字 = 音+音**（短复合词=音读组合）
6. **5拍双字 = 有训读**（长复合词=至少一方训读）
7. **浊音不二**（浊辅音g/z/d/b在一个词干内不重复）
