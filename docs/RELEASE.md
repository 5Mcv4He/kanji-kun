## 执行摘要

JLPT N5–N1 的全部词汇中，表面标注为训读的实例是 **4,316 个**。传统的学习方式将这些实例视为独立的记忆项——每遇到一个词记一个读法。

本项目通过五层压缩管线、四维评估框架和逐字标注数据分析，证明了：

**真正需要你有意识地记忆的，约为 1,087 项（外加 25 条一次性规则）。压缩比 4.0:1。**

消失的那约 3,200 项不是被"技巧"绕过的——它们是日语本身的结构决定的。活用形变体、形态派生、跨级复用和词干连带效应，将这些表面实例压到了它们本来该有的大小。

本项目做了一件事：**把不该记的东西从清单里划掉，给该记的东西排出最优顺序。** 在日语语言学允许的边界内，该方法已经到了尽头。

## 项目做了什么

### 1. 建立了 JLPT 训读的完整数据集

- `kun_v9_data.json`（3.1MB）：8,375 个 JLPT 词汇，逐字标注音读/训读分类 + 词干提取，总准确率 99.4%
- `kun_v8_reverse_index.json`（8.5MB）：7,644 读法→汉字映射，200 词干→汉字聚类
- 数据基础：漢字検索 V2（46,849 汉字）+ JLPT 红宝书词汇表

### 2. 设计并实现了五层压缩管线

| 层 | 操作 | 效果 |
|----|------|------|
| Layer 1 | 活用形归并 | 4,316 → 1,892（省 56.2%） |
| Layer 2 | 形态词根聚类（5-pass） | 1,892 → 1,703（省 10.0%） |
| Layer 3 | 跨级复用 | 累计新词根 = 1,703（省 39.0%） |
| Layer 4 | 词干连带（3 层权重） | 1,703 → 1,087（强 465 + 中 249 + 弱 552） |

Layer 2 的 5-pass 算法是保守性设计的核心——仅在使用语言学上有效的规则时合并（限定后缀列表、检查语法结尾类型），与简易克隆算法对比（1,634 vs 1,703），确认诊断版本更保守，拒绝 69 次可疑合并。

### 3. 构建了四维评估框架

- **维度一：压缩比** — 4.0:1（目标 ≥4:1 ✓）
- **维度二：层级递进** — 逐级复用率 N4=25.2%, N3=39.9%, N2=46.9%, N1=44.9%
- **维度三：锚点覆盖** — 99.7% 对可归入至少一个锚点类型，54.8% 有 3+ 锚点
- **维度四：陷阱标记** — 90 多训字 + 123 同音异字 + 70 形近异训 + 29 重度陷阱

### 4. 验证了 15 项核心发现

**肯定发现（10 项）**：音训判断规则（6 条，覆盖 91%）、自他对应系统（10 模式）、送假名词类规则（9 条）、帕累托频率优先、词干连带效应、跨级复利效应、活用形归并、形态派生归并、部首锚点分层、陷阱全标记。

**否定发现（5 项）**：形近字极少共享读法（0.2-0.6%）、部首互信息不足以预测读法、语义域约束力微弱（域内熵 5-7 bits）、ML 聚类未发现隐藏深层结构、送假名→读法末元音预测力极弱。

否定发现的重要性不亚于肯定发现——它们告诉你**什么路走不通**。三种方法（规则推导、特征交叉穷举、ML 聚类）、三十多个维度，全部确认：训读无全局推导规则。

## 已知限制

1. **词干连带权重是估计值**：基于认知心理学类比迁移理论，非经验测量。有效项在 961（激进）至 1,214（保守）之间波动，居中值为 1,087。
2. **自他动词检测为下限**：V9 存储词干不含送假名，导致后缀匹配模式损失部分对。完整读法下覆盖更高。
3. **不适用于非汉语母语者**：系统前提假设（汉字识别免费、语义空间共享）仅对汉语母语者成立。
4. **不涵盖 N1 以上**：古典日语、汉文训读属于另一问题域。
5. **不扩展到音读**：音读对中文母语者近乎免费，不需要另外的系统。

## 学习者如何使用

### 如果你从零开始

1. 读 `output/kun_final_system.md` 序章和第一章（30 分钟）——理解为什么大部分"训读实例"不需要记
2. 读第二章（15 分钟）——学会 6 条音训判断规则
3. 按第三章的 N5 前 20 步开始，每天 5-10 个词干
4. 学完 N5 全部 400 对后，进入 N4——你会发现 25% 已经会了
5. 逐级推进到 N1——每级复用率递增，越学越快
6. 复习时用速查卡（附录 A）和各级记忆指南（`memorize_N5.md`–`memorize_N1.md`）

### 如果你已经学了一部分

1. 读 `kun_final_system.md` 第四章（复利层）——确认你已学的部分有多少可以跨级复用
2. 用诊断报告的层级递进表定位你当前级别的新增量
3. 重点攻克每级的"全新"部分，已见过的直接跳过

## 项目边界：明确不做的事

- **不编"记忆口诀"**。三种方法、三十多个维度穷举确认：训读无全局推导规则。任何声称"训读推导公式"的说法，要么覆盖率极低，要么事后凑答案。
- **不扩展到音读**。音读对中文母语者≈听方言。
- **不涵盖 N1 以上**。系统的边界就是 JLPT 的边界。
- **不适用于非汉语母语者**。英语母语者需要同时建立形、义、音读、训读四个映射——本系统的核心前提不成立。
