## 1. 项目概述

### 1.1 目标

以 JLPT N5–N1 为边界,为中国母语者构建训读学习的最优系统。核心指标:

- **压缩比 ≥ 4:1**: 将表面训读实例压至 1/4 以下,只保留真正需要记忆的项
- **跨级复用 N4≥30%, N1≥50%**: 前级学过的后级自动覆盖
- **记忆锚点覆盖率 ≥ 90%**: 每个需记项都有清晰的记忆挂钩
- **陷阱全标记**: 多训字、同音异字、形近异训、重度陷阱

### 1.2 核心命题

> 训读不是"汉字的日本发音",而是**和语词的汉字书写方式**。

这个视角转换是整个系统的逻辑基础。JLPT 表面 4,316 个训读实例中,约 75% 可以通过语法归并、形态聚类、跨级复用和词干连带消除——它们根本不应该作为独立记忆项存在。

### 1.3 适用范围

- **包含**: JLPT N5–N1 全部词汇的训读部分
- **不包含**: 音读(对中国学习者近乎免费)、N1 以上古典日语、汉文训读
- **学习者前提**: 汉语母语,已认识汉字形/义

## 3. 算法详解

### 3.1 五层压缩管线

```
Layer 0: 表面实例    4,316  (每个词中每个汉字的每次出现)
Layer 1: 活用形归并  1,892  (書く/書きます/書いて→同一对)    56.2% savings
Layer 2: 形态词根    1,703  (上がる/上げる→同一词根)        10.0% savings
Layer 3: 跨级复用    1,703  (N4有25%在N5已出现,不重计)     39.0% savings
Layer 4: 词干连带    1,087  (共享词干的后续字学习量打3-7折)  —
```

#### Layer 1: 活用形归并

```python
# 去重: 同一个(汉字, 词干)对,不论出现在多少活用形中,只计一次
pairs = set((gt['kanji'], gt['reading']) for all kun instances)
```

这是最简单的操作: `書く=か`, `書きます=か`, `書いて=か` → 只保留一个 `(書, か)`。

#### Layer 2: 形态词根聚类 (5-Pass Algorithm)

```python
def readings_to_roots_v3(readings):
    """5-pass root clustering"""
    # Pass 1: 自他对应 (e.g. 上がる↔上げる → same root)
    # Pass 2: 连浊变体 (e.g. か↔が, same-length, same trailing moras)
    # Pass 3: 词干+后缀 (e.g. い→いかす, with valid suffix list)
    # Pass 4: 同首拍+动词/名词结尾 (same length, same 1st mora)
    # Pass 5: 同首2拍 (different lengths, same first 2 moras)
```

**保守性设计**: 仅在使用语言学上有效的规则时合并(限定后缀列表、检查语法结尾类型)。与简易克隆算法对比: 诊断 1,703 词根 vs 克隆 1,634 — 诊断更保守,拒绝 69 次可疑合并。

#### Layer 3: 跨级复用

每个(汉字,词根)对标记其首次出现的 JLPT 级别。后续级别出现的同一词根不计入"新记忆"。

```
N5 完成: 383 词根(全部新)
N4 完成: +281 新(107 已在前级出现 = 26.4% 复用)
N3 完成: +337 新(237 已在前级 = 40.5%)
N2 完成: +315 新(320 = 49.9%)
N1 完成: +407 新(372 = 47.8%)
             累计新词根: 1,703
```

#### Layer 4: 词干连带 (3-Tier Carry-Over)

```
强连带 (weight 0.3): 共享前2拍 + 前级已学      → 465 词根, 省 70%
中连带 (weight 0.5): 共享1拍 + 同语义域 + 前级   → 249 词根, 省 50%
弱连带 (weight 0.7): 共享1拍 + ≥3字共用 + 前级   → 552 词根, 省 30%
```

**权重说明**: 0.3/0.5/0.7 基于认知心理学中类比迁移的估计,非经验测量。保守权重(0.4/0.6/0.8)下有效项=1,214(3.6:1),激进(0.2/0.4/0.6)下=961(4.5:1),文档采用居中值。

### 3.2 四维评估框架

- **维度一: 压缩比** — 5 层管线, surface / effective
- **维度二: 层级递进** — 每级的 genuine reuse rate + root reuse rate
- **维度三: 锚点覆盖** — 7 种锚点类型, 含部首质量分层
- **维度四: 陷阱标记** — 4 类陷阱, 形近检测用有意义部首(排除笔画级)

## 6. 已验证的发现

### 6.1 肯定发现 (10项)

1. **音训判断规则**: 6 条, 覆盖 91% JLPT 词汇
2. **自他对应系统**: 10 个模式(覆盖 2.7–11.9%/级)。V9 检测到 73 对跨汉字自他(为下限,因词干不含送假名)
3. **送假名词类规则**: 9 条, 覆盖 40–44% 带假名实例
4. **帕累托频率优先**: 前 124 字覆盖 N3 的 50%
5. **词干连带效应**: 3 层(强/中/弱), 共享词干的后续字学习量降为 30–70%
6. **跨级复利效应**: 逐级递进, 25–47% 复用率
7. **活用形归并**: 56.2% 表面实例为活用变体
8. **形态派生归并**: 5 步算法归并 10.0%
9. **部首锚点分层**: 97.3% 覆盖, 强层(≥10成员)1,229 对, 中层(5-9)350, 弱层(2-4)262
10. **陷阱全标记**: 90 多训 + 123 同音 + 70 形近(有意义部首级) + 29 重度

### 6.2 否定发现 (5项) — 同样重要

1. **形近字极少共享读法**(0.2–0.6%) → "训读声旁"概念不成立
2. **部首对读法的互信息不足以支撑预测** → 不能靠部首猜训读
3. **语义域对读法的约束力微弱**(域内熵 5–7 bits) → 知道语义不能预测读法
4. **ML 聚类未发现人类遗漏的深层结构** → 30+ 维空间中聚类由表层音韵驱动
5. **送假名→读法末元音预测力极弱**(N2 级别 0 个强预测) → 假名不能告诉你读法结尾

## 7. 限制与边界

### 7.1 已知限制

- **词干连带权重是估计值**: 基于认知心理学类比迁移理论, 非经验测量; 有效项在 961–1,214 之间波动
- **N4/N1 复用率未达标**: 25.2%(目标 30%)和 44.9%(目标 50%) — 原因是 JLPT 级别设计的结构性上限, 66% 的 N4 汉字在 N5 中不出现
- **自他动词检测为下限**: V9 存储词干不含送假名, 导致后缀匹配模式损失部分对
- **部首数据来自漢字検索V2**: 分类准确但不覆盖所有 JLPT 汉字
- **不适用于非汉语母语者**: 系统前提假设(汉字识别免费、语义空间共享)仅对汉语母语者成立

### 7.2 明确不做的事

- 不编"记忆口诀"(训读无全局推导规则, 三种方法+30+维度穷举确认)
- 不扩展到音读(音读对中文母语者近乎免费)
- 不涵盖 N1 以上(古典日语、汉文训读属于另一问题域)
