## Thread

**1/** 跑完全部JLPT词汇后一个反直觉发现：训读的四分之三不需要记。

4,316个表面实例 → 过滤活用形、自他对、形态派生 → 剩约1,100个词根。日语语法替你扛了75%。

**2/** 先扭一个视角。

「訓読み」这个词在误导你——听起来像"汉字有日本读法"。不是的。日语里只有一个「はかる」，称重用「量る」，测长用「測る」，图谋用「謀る」。你学的是一个日语词，汉字只是它穿的衣服。

**3/** 剩下1,100个词根，用三种走法串。

词干家族260个：「書=か」「買=か」「変=か」——同一个读音。学了第一个，后面全是确认。
自他模式10个：〜う↔〜える 一个模式管一批。
部首文件夹15个：水部全跟液体有关。

**4/** 最狠的数据：跨级复用。

N4的词根有25%在N5已出现。N3→39.9%。N2→46.9%。每升一级，将近一半不是新的。你不是在学更多——你是在确认更多。

**5/** 这三种走法我都跑过数据验证。词干家族交叉验证（同一读音至少在两个不同JLPT词中出现），自他模式覆盖率用实际动词对计算，压缩比每层有去重前后的计数对比。

**6/** 结论：训读不是背的，是逛的。
